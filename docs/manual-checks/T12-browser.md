# T12 수동 확인 — 서버 문제와 연출 (D34, D36~D40, D48의 화면 부분)

자동 시험(`apps/server/src/math*.test.ts`, `apps/web/src/lib/stage/server-math.test.ts`, `apps/web/tests/e2e/math.spec.ts`)은 서버 판정과 글 띠, DOM을 확인한다. 이 문서는 캔버스 연출(정답 포탄, 업그레이드·재질·진화 연출)과 오래 기다려야 하는 상태(찍기 의심 5분, 하루 151번째, 건너뛰기 대기)를 눈으로 본다.

## 준비

```sh
# 게임 서버: 시험용 DB 파일 (끝나면 이 PID를 끄고 DB 폴더를 지운다)
mkdir -p /tmp/ktd-t12 && cd apps/server
ALLOWED_ORIGIN=http://localhost:3129 SESSION_SECRET=manual-check-only-0123456789abcdefgh DB_PATH=/tmp/ktd-t12/ktd.db PORT=4000 node --import tsx src/main.ts
# 웹: dev 서버(3129)가 이미 떠 있으면 그것을 쓴다
```

브라우저로 `http://localhost:3129/`에서 처음 하기(3~4학년)를 마치고 방어 화면으로 간다. DB 값을 바꾸는 단계는 `sqlite3 /tmp/ktd-t12/ktd.db`로 한다(지킴이가 하나뿐이므로 `WHERE` 없이 쓴다). 값을 바꾼 뒤에는 화면을 새로 고친다.

## 확인 항목

| # | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 1초 넘게 생각하고 정답을 누른다(틀리면 "다음 문제"를 눌러 다시) | 내 타워가 바로 큰 정답 포탄을 쏜다. "+10P", "내 타워 2단계!" 띠, 막대의 단계 숫자 2. 0.8초 뒤 새 문제 |
| 2 | 오답을 누른다 | 고른 보기에 "✕ 내가 고른 답", 정답 보기 강조, 풀이 1~2줄, "괜찮아요, 다음 문제에서 또 해 봐요". 패널 높이가 바뀌지 않는다. "다음 문제"를 누를 때까지 남는다 |
| 3 | 문제가 뜨자마자(1초 안) 정답을 누른다 | 정답 표시와 "천천히 풀어도 괜찮아요", 포인트 0 |
| 4 | 새로 고친다 | 같은 문제가 그대로 나온다 |
| 5 | 2단계에서 `UPDATE guardians SET wallet = 5000;` 뒤 정답 1개 | 25단계를 넘어 여러 단계를 한 번에 올라간다. 가장 큰 변화인 진화 연출(빛기둥, "진화!"로 시작하는 띠)이 나오고 막대의 단계 숫자가 바뀐다. 남은 포인트는 업그레이드 게이지에 남는다 |
| 6 | `UPDATE guardians SET today_on = date('now', '+9 hours'), today_correct = 150;` 뒤 정답 1개 | "+5P", "오늘 정말 많이 풀었어요! 쉬어 가도 괜찮아요" 띠가 한 번, 머리줄 "쉬어 가도 괜찮아요 · 지금은 포인트 절반" |
| 7 | 1초 안에 아무 보기나 누르고 "다음 문제"를 20번 되풀이한다 | 20번째 무렵 머리줄이 빨간 "포인트 멈춤 4:59 · 문제를 천천히 읽어 봐요"로 바뀌고 1초마다 줄어든다. 문제는 계속 풀 수 있다 |
| 8 | 11번 연달아 "건너뛰기" | 11번째 뒤 머리줄 "잠깐 쉬었다 해요 · 10초 뒤에 다음 문제", 보기가 잠기고 10초 뒤 새 문제 |
| 9 | 운영체제에서 "동작 줄이기"를 켜고 1을 다시 | 흔들림·깜빡임 없이 띠와 숫자만 바뀐다 |

## 뒷정리

게임 서버 PID를 끄고 `/tmp/ktd-t12`를 지운다. 3129 dev 서버는 원래 떠 있던 것이면 끄지 않는다.
