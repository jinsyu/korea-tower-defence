# T13 수동 확인 — 지역 방송을 따라가는 방어 화면, 지난 소식, 연결 순서 (D21~D24, D58, D77의 화면 부분)

자동 시험(`apps/server/src/live.test.ts`, `restart.test.ts`, `packages/core/src/game/news.test.ts`, `packages/core/src/stage/reps.test.ts`, `apps/web/tests/e2e/region.spec.ts`, `connect.spec.ts`)은 서버 결과와 화면 DOM(웨이브 기록, 머리줄 수치, 알림)을 확인한다. 이 문서는 캔버스 연출이 서버 웨이브를 따라가는지, 대표 타워가 보드에 놓이는지, 1시간 넘게 떠났다 오는 "지난 소식"을 눈으로 본다. 실제 도메인·IP·프록시 세 길은 배포(T20) 뒤에 다시 본다(아래 7).

## 준비

```sh
# 게임 서버: 시험용 DB, 60배속 시계(실제 1분 = 서버 1시간). 끝나면 이 PID를 끄고 DB 폴더를 지운다.
mkdir -p /tmp/ktd-t13 && cd apps/server && export FROM=$(date +%s000)  # 6에서 다시 켤 때 같은 값
ALLOWED_ORIGIN=http://localhost:3129 SESSION_SECRET=manual-check-only-0123456789abcdefgh DB_PATH=/tmp/ktd-t13/ktd.db PORT=4000 \
  TEST_CLOCK_RATE=60 TEST_CLOCK_FROM_MS=$FROM node --import tsx src/main.ts
# 웹: dev 서버(3129)가 이미 떠 있으면 그것을 쓴다. NEXT_PUBLIC_RT_URLS가 비어 있으면 127.0.0.1:4000으로 붙는다.
```

브라우저로 `http://localhost:3129/`에서 처음 하기(3~4학년)를 마치고 방어 화면으로 간다. 60배속에서는 웨이브가 실제 1초마다 하나씩 끝난다. 연출을 보통 속도로 보려면 `TEST_CLOCK_RATE` 없이 띄운다(웨이브 60초).

## 확인 항목

| # | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 방어 화면을 연다 | 2초 안에 머리줄 웨이브 숫자와 P/적 수치가 나온다("–"에서 바뀜). 위 띠에 "지금 N명이 함께 지키는 중 · 최고 웨이브 N (전국 N위)"가 보인다 |
| 2 | 1배속 서버로 웨이브 끝을 지켜본다 | 서버가 막음이면 적이 성문 전에 쓰러지고 "웨이브 N 막음", 뚫림이면 "웨이브 N 뚫림 · 방어선 재정비, 웨이브 M부터 다시"가 나온다. 연출이 서버 판정과 반대로 끝나지 않는다 |
| 3 | 정답 몇 개 뒤 10초 기다린다 | 다음 웨이브부터 P가 늘어난다(10초 모으기, 그 웨이브 도중에는 바뀌지 않음) |
| 4 | 같은 지역으로 지킴이 2명을 더 만들고(다른 브라우저 프로필) 각자 정답 몇 개 | 10분(60배속이면 10초) 안에 내 보드에 대표 타워가 나타나고, 내 타워는 늘 한 개만 보인다. 내가 1등이면 내 타워가 첫 대표 자리로 옮긴다 |
| 5 | 탭을 닫고 1분 30초(서버 1시간 30분) 뒤 다시 연다 | "지난 소식" 시트(NewsSheet)에 그동안 막은 웨이브 수, 뚫림 수, 최고 웨이브·순위 변화가 나온다. 1분 안에 다시 열면 나오지 않는다 |
| 6 | 서버 PID를 끄고, 10초 뒤 같은 셸에서 같은 명령(같은 `$FROM`)으로 다시 켠다 | 끄고 3초 안에 보드에 "중계 연결이 끊겼어요, 다시 잇는 중…" 알림과 머리줄 "연결 끊김", 보기가 잠긴다. 켜면 알림이 사라지고 같은 문제가 그대로 열려 있으며 웨이브가 1로 돌아가지 않는다 |
| 7 | (배포 뒤, T20) 학교망 흉내: 브라우저 개발자 도구의 요청 차단으로 도메인 → 도메인과 IP를 차례로 막고 새로 고친다 | 각각 IP 경로(`/ktd/socket.io`, WebSocket), 이 사이트의 `/rt`(long polling)로 붙어 1과 같이 동작한다. 게임 서버 `/health`의 `sockets.ip`, `sockets.proxy`가 늘어난다 |
| 8 | 운영체제에서 "동작 줄이기"를 켜고 2를 다시 | 흔들림 없이 웨이브 결과 띠와 숫자만 바뀐다 |

## 뒷정리

게임 서버 PID를 끄고 `/tmp/ktd-t13`을 지운다. 3129 dev 서버는 원래 떠 있던 것이면 끄지 않는다.
