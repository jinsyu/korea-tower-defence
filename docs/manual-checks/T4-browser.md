# T4 수동 확인 — 에셋 견본 (D51, D78 사람 확인 부분)

자동 시험(`apps/web/src/lib/art/art.test.ts`, `packages/core/src/looks.test.ts`, `balloons.test.ts`)이 다루지 못하는 "눈으로 구별되는가"를 확인한다.

## 준비

```sh
pnpm --filter web build
cd apps/web && pnpm exec next start -p 3000   # 끝나면 이 PID를 끈다
```

브라우저로 `http://localhost:3000/dev/assets`를 연다. 비교 기준: 확정 시안 `docs/design/mockups/option-b.html?screen=assets`.

## 확인 항목

| # | 보기 | 할 일 | 기대 결과 |
|---|---|---|---|
| 1 | 실루엣 | "실루엣" 버튼을 누르고 "자리 44px" 카드를 본다 | 같은 문턱 열에서 스피드건(좁고 뾰족)·물대포(넓고 낮은 통)·끈끈 테이프(네모 + 롤) 3개가 검은 모양만으로 구별된다 |
| 2 | 실루엣 | 같은 카드에서 한 줄(계열 하나)을 본다 | 1·25·100·200·500단계(I~V) 5개가 서로 다른 모양이다(II 어깨 부착물, III 계열 특징, IV 키 +15%·왕관, V 날개·광륜) |
| 3 | 보통 | "자리 44px" 카드에서 1·50·100·200·300·500단계 받침 테두리를 본다 | 흰·초록·파랑·보라·주황·금 6색이 구별되고, 500단계에 ★가 보인다. 단계 숫자 배지가 읽힌다 |
| 4 | 회색조 | "회색조"를 누르고 1~3을 다시 본다 | 계열·진화 단계가 여전히 구별된다 |
| 5 | 흐림 2px | "흐림 2px"를 누르고 44px 카드를 본다 | 계열 3개와 진화 단계가 여전히 구별된다 |
| 6 | 회색조 | 풍선 카드를 본다 | 보통(둥근)·쌩쌩(기운 물방울 + 고글)·왕(띠 두른 둥근 + 왕관)·대장(가로 비행선) 4종이 색 없이 크기와 모양으로 구별된다 |
| 7 | 보통 | 풍선 카드의 "왕 · 절반", "대장 · 66%", "대장 · 33%"를 본다 | 왕은 아래 띠가 끊겨 있고, 대장은 66%에서 반창고 1개, 33%에서 반창고 2개와 주름이 보인다 |
| 8 | - | 이웃한 5단계 묶음 대표 30쌍(88px) | 견본 화면에는 문턱 8개만 있어 여기서는 볼 수 없다. 자동 시험이 계열마다 100묶음의 이웃 쌍 픽셀이 다름을 확인하고, 사람 확인은 내 타워 화면(T8) 미리보기에서 한다 |

## 기록

통과하지 못한 항목은 단계, 계열, 보기 방식, 스크린샷 경로를 적어 그림 코드(`apps/web/src/lib/art/tower.ts`)를 고친다.
